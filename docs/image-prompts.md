# Bild-Prompts für Nano Banana

Ein Prompt pro Bildplatz, jeweils vollständig (Stil steckt in jedem Prompt). Dateinamen und Formate wie in [images.md](images.md).

## Tipps

- Generate all images in one session. Use the first good result (ideally the home hero) as a reference image for the rest and add: "Match the lighting, color palette and render style of the reference image."
- Set the aspect ratio in Nano Banana itself when it offers the option; the prompts also state it.
- The three avatar images (Home card 3, Coaching Tools hero and whiteboard) should show the same avatar style. Generate them one after another and reuse the first as a reference.
- If letters or words appear on a whiteboard or door, ask for a correction: "Remove all text and letters, keep everything else."
- Deliver as PNG or JPG in the highest resolution. I'll convert them to WebP, crop them to the right format and put them into the repo.
